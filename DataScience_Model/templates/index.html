Hypothesis Testing

Run T-test, Chi-test, and ANOVA with related visuals and outlier details.

How to read the results

  • p-value: If p < 0.05, we reject H0 (evidence of difference/association).
  • T-test: compares mean of a numeric metric between two groups (malicious vs normal).
  • ANOVA: tests whether group means differ across 3+ categories, using variance (F-statistic = between-group variance / within-group variance).
  • Chi-square: checks association between two categorical variables.
  • Outliers: unusual values using IQR bounds; count helps spot extreme behavior.

Conclusion: If we reject H0, the selected factor is statistically linked to behavior differences and can be a useful signal.

  • Trend plot: average signal per day (`trip_day_number`) plus a rolling mean to show the overall direction.
  • Forecast plot: compares actual vs predicted values on the test split.
  • RMSE/MAE: forecast error (lower = better).

Conclusion: The conclusion line tells which method performed better on the test split (lower RMSE).
